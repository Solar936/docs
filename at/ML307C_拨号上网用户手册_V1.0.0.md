3.2.1. USB串口驱动内核配置
RNDIS拨号依赖于Linux上位机对应的内核驱动。
方法一：通过命令行make menuconfig配置
-> Device Drivers
-> Network device support (NETDEVICES [=y])
-> USB Network Adapters (USB_NET_DRIVERS [=m])

<M> Host for RNDIS and ActiveSync devices
方法二：通过修改.config文件进行配置
CONFIG_NETDEVICES=y
CONFIG_USB_NET_DRIVERS=m
CONFIG_USB_USBNET=m
CONFIG_USB_NET_RNDIS_HOST=m
配置完毕后，重新编译内核，Linux系统即可识别到模组RNDIS网卡设备。
rndis_host 3-2:1.0 eth0: register 'rndis_host' at usb-0000:03:00.0-2, RNDIS device
